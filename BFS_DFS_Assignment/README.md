# BFS and DFS Implementation

## Description

This project implements two graph traversal algorithms, **Breadth First Search (BFS)** and **Depth First Search (DFS)**, using Python.

## Algorithms Used

### BFS

BFS visits the graph level by level and uses a **queue** for traversal.

### DFS

DFS explores one path as deeply as possible before backtracking. It uses **recursion** for traversal.

## Test Cases

The program tests both algorithms using different starting vertices such as:

* A
* B
* C

## Time Complexity

Both BFS and DFS have a time complexity of **O(V + E)**, where `V` is the number of vertices and `E` is the number of edges.

## Technologies Used

* Python
* `collections.deque`

## How to Run

python bfs_dfs.py
